# مرجعك القانوني

موقع عربي ثابت للبحث في:

- قانون العمل رقم 14 لسنة 2025 (المواد 1–298).
- قانون التأمينات الاجتماعية والمعاشات رقم 148 لسنة 2019 (المواد 1–170).

## التشغيل

شغّل مجلد المشروع عبر أي خادم ملفات ثابت، ثم افتح `index.html`. يلزم الخادم لأن بيانات القوانين تُحمّل من `data/laws.json`.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع **محتويات هذا المجلد** إلى جذر المستودع، بحيث يكون `index.html` في الجذر مباشرة.
3. افتح `Settings` ثم `Pages`.
4. اختر `Deploy from a branch`، ثم فرع `main` والمجلد `/ (root)`.
5. احفظ الإعداد وانتظر ظهور رابط الموقع.

الموقع لا يحتاج إلى بناء أو خادم خلفي أو مفاتيح API. جميع المسارات نسبية، ولذلك يعمل على رابط مستودع فرعي في GitHub Pages.

## تنبيه

الموقع مرجع بحثي لتيسير الوصول إلى النصوص ولا يُعد استشارة قانونية. يجب مراجعة الجريدة الرسمية والتعديلات السارية عند الاستخدام المهني.
